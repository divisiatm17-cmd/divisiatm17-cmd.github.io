Buka Aplikasi

Android

  1. Pakai APK — unduh AngkutAja-Admin.apk, lalu pasang (izinkan "Instal dari sumber tidak dikenal").
  2. Tanpa APK — buka Chrome, tekan menu ⋮ → Tambahkan ke layar utama.
  3. Ikon aplikasi muncul di layar utama seperti aplikasi biasa.

iPhone / iPad

  1. Buka tautan aplikasi ini di Safari (bukan Chrome).
  2. Tekan tombol Bagikan (kotak dengan panah ke atas).
  3. Pilih Tambahkan ke Layar Utama, lalu Tambah.
  4. Aplikasi tampil penuh layar tanpa alamat web — seperti aplikasi asli.
Unduh Profil iOS (otomatis)
Cara pasang profil: setelah diunduh, buka Pengaturan → Umum → VPN & Perangkat → Profil → pilih AngkutAja Admin → Pasang.
